### 🧠 What I'm working on

- **Multi-agent AI for data lineage** — tracing variables across ~80,000 COBOL/JCL files (~24.5M lines) for a large European financial group, with regulatory deliverables aligned with ECB requirements.
- **Knowledge Graph + GraphRAG for codebase intelligence** — multi-repository graphs (COBOL/JCL, Java, JS/TS, Python) built from AST parsing (ANTLR4), enriched by LLMs, indexed in Neo4j and queried with hybrid retrieval and tool calling.
- **AI governance** — a LiteLLM-based proxy shaped as a product.

Client names stay private (NDA) — the details are on my [portfolio](https://portfolio.eduardferre.dev).
